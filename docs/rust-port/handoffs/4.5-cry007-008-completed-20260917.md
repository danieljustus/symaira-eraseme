## Implemented scope

1. **Interprocess database locking (`crates/symeraseme-core/src/storage/locking.rs`):**
   - `DbLock` matching Go's `eventstore.DBLock`.
   - Acquires non-blocking exclusive flock (`fs2`) on `<db_path>.lock`.
   - POSIX file mode `0o600`.
   - Safe release on `close()` and on `Drop`.

2. **Encrypted at-rest lifecycle & durability (`crates/symeraseme-core/src/storage/encrypted_store.rs`):**
   - `open_encrypted`:
     - Ensures private directories (`0700`) and files (`0600`).
     - Holds exclusive interprocess `DbLock` for store lifetime.
     - Automatically initializes new SQLite databases via temporary private files, checkpoints, and publishes ciphertext.
     - Transparently decrypts to temporary private SQLite file (`symeraseme_decrypted_*.db`) with mode `0600`.
     - Automatically migrates older V1, V2, and legacy Go V3 envelopes to standard Fernet V3 on open.
   - `open_configured`:
     - Single production entry point for CLI and MCP engines.
     - Rejects encryption requests immediately if master key is unavailable.
     - Supports seamless plaintext ↔ encrypted conversions while preserving data integrity.
   - Durability (`CRY-008`):
     - `checkpoint_wal_conn` runs `PRAGMA wal_checkpoint(TRUNCATE)` and inspects all three result columns (`busy`, `log_frames`, `checkpointed`).
     - `close`: checkpoints WAL, drops SQLite handle, reads plaintext, encrypts to V3, and uses atomic transition (`atomic_transition_with_recovery`) with parent directory `fsync`.
     - Cleans up temporary plaintext DB and removes `-wal` / `-shm` sidecars.
   - Cleanup & Scavenging (`CRY-007`):
     - `scavenge_stale_temps`: removes orphaned temporary files matching standard prefixes (`symeraseme_decrypted_`, `symeraseme_init_`, `.symeraseme_write_`, `.symeraseme_recovery_`, `.symeraseme_previous_`) older than 300 seconds, including WAL/SHM siblings.
     - `remove_wal_siblings`: removes `-wal` and `-shm` siblings.
     - `finalise_all`: finalizes all registered stores on demand.

3. **Envelope format helpers (`crates/symeraseme-core/src/storage/encryption.rs`):**
   - `EnvelopeVersion` (`V1`, `V2`, `V3`).
   - `detect_version(raw) -> Option<EnvelopeVersion>`.
   - `is_encrypted(raw) -> bool`.
   - `decrypt_any(raw, master_key) -> Result<Vec<u8>, EncryptionError>`.
