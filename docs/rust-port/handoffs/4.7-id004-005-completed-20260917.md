## Implemented scope

1. **Consent Token Lifecycle & Storage (`crates/symeraseme-core/src/identity/consent.rs`):**
   - SHA-256 token hashing (`consent_<sha256[:16]>.json`) with legacy unhashed token auto-migration.
   - Atomic token issuance (`issue_token`) with temporary file write, sync, checked close, chmod, and atomic rename.
   - Expired token auto-pruning on `verify_token`, `list_tokens`, and `revoke_all`.
   - Idempotent token single-use consumption (`consume_token`) and revocation (`revoke_token`).
   - `revoke_all`: revokes all active tokens in the store and returns the exact count of removed tokens.

2. **Grant Contract & Payload Engine (`crates/symeraseme-core/src/identity/consent.rs`):**
   - `GrantOptions` and `GrantOutcome` types matching Go MCP `grant` and CLI-017:
     - `list_tokens`: returns `GrantOutcome::List { success: true, tokens, count }`
     - `dry_run`: preview without mutating disk, returns `GrantOutcome::DryRun { success: true, dry_run: true, command, revoke, revoke_all }`
     - `revoke_all`: returns `GrantOutcome::RevokeAll { success: true, revoked, revoke_all: true }`
     - `revoke`: revokes single token or returns `ConsentError::NotFound` if missing, returns `GrantOutcome::RevokeOne { success: true, revoked: 1 }`
     - `issue`: issues fresh token with command (default `"execute"`) and TTL (default 86400), returns `GrantOutcome::Issue { success: true, token }`
   - `ConsentStore::grant`: orchestrates all five modes matching Go contract handler behavior.

3. **Destructive Operations Gate & Non-Interactive MCP Enforcement (`crates/symeraseme-core/src/identity/gate.rs`):**
   - Precedence chain: `--yes` > explicit token > consent file > env token > env file > fails closed.
   - MCP non-interactive restriction: no interactive TTY prompt in core; requests without consent tokens fail closed with `ConsentError::Denied`.
   - Single-use enforcement: verified tokens are consumed immediately upon authorization; subsequent reuse fails closed.
   - `consent_gate`: top-level convenience helper evaluating default data directory store.
