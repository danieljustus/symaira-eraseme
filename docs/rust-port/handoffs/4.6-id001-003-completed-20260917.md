## Implemented scope

1. **Canonical JSON Serialization & Deterministic Hashing (`crates/symeraseme-core/src/identity/profile.rs`):**
   - `canonical_generic_json`: serializes arbitrary JSON data into canonical Python JSON representation matching Python's `json.dumps(..., sort_keys=True, ensure_ascii=True)` and Go's `CanonicalGenericJSON`.
   - `canonical_json(&Profile)`: normalizes empty collections to `[]` (never `null`), serializes address fields with sorted keys, and applies Python `ensure_ascii=True` string escaping (`\u{:04x}` for non-ASCII characters).
   - `hash_profile(&Profile)`: returns 64-character lowercase hexadecimal SHA-256 digest of `canonical_json`.

2. **Authenticated Profile Encryption & Decryption (`crates/symeraseme-core/src/identity/profile.rs`):**
   - `encrypt_profile_with_nonce`: creates envelope version 2 `{"version": 2, "nonce": "<hex>", "algorithm": "AES-256-GCM"}`, seals plaintext with AES-256-GCM using envelope JSON as AAD.
   - `encrypt_profile`: generates 12-byte CSPRNG nonce via OS CSPRNG and delegates to `encrypt_profile_with_nonce`.
   - `decrypt_profile_with_key`: parses header, validates nonce length (12 bytes), validates version > 0 (rejecting legacy v0), and decrypts payload using header bytes as AAD.
   - `load_profile`: validates envelope structure and header before querying master key, decrypts, and zeroizes plaintext bytes.

3. **Filesystem Lifecycle & Durability (`crates/symeraseme-core/src/identity/profile.rs`):**
   - `ProfilePaths::resolve_write`: resolves write destination matching Go rules (`SYMERASEME_IDENTITY_PATH` -> `SYMERASEME_DATA_DIR` -> `~/.symeraseme/identity.encrypted`).
   - `save_profile`: creates parent directory with `0o700` permissions, writes encrypted payload via temporary file with `0o600` permissions, calls file `fsync`, atomically renames over target, and calls parent directory `fsync`. Cleans up temp file on failure.
   - `delete_profile`: removes target file, maps missing file to `ProfileError::NotFound`.
   - `init_profile`: resolves existing key or generates fresh key, caching in-process, then saves profile.

4. **Bidirectional Go Parity Oracle (`rust-tests/parity/oracle/identity/main.go`):**
   - Stdin protocol supporting:
     - `'e'`: EncryptProfileWithKey
     - `'d'`: DecryptProfileWithKey
     - `'c'`: CanonicalJSON
     - `'h'`: HashProfile
     - `'s'`: SaveProfile
     - `'l'`: LoadProfile

5. **Test Suite:**
   - `crates/symeraseme-core/tests/identity_interop.rs` (ID-001):
     - Provenance vectors: decrypts Python-final `minimal.enc`, `full.enc`, `unicode.enc` against `provenance.json`, matching exact canonical JSON and SHA-256 hash.
     - Rust writer -> Go reader: Go oracle decrypts Rust ciphertext and computes identical canonical JSON and hash.
     - Go writer -> Rust reader: Rust decrypts Go ciphertext and computes identical canonical JSON and hash.
     - Full roundtrip: Go saves to disk -> Rust loads -> Rust modifies & saves -> Go loads, verifying 100% data integrity.
     - Permissions & modes: 0600 file mode, 0700 dir mode, no orphaned temp files.
     - Tampering & corruption: modified ciphertext, tampered header, truncated envelope, and wrong keys fail closed.
   - `crates/symeraseme-core/tests/identity_secret_resolution.rs` (ID-002, ID-003):
     - Master-key precedence: Cache -> Direct Hex (`SYMERASEME_IDENTITY_MASTER_KEY`) -> Scrypt Passphrase (`SYMVAULT_PASSPHRASE`) -> Keyring -> Missing.
     - Aliases: `symvault://` and legacy `vault://`.
     - Fallbacks: environment fallback and keyring fallback.
     - Native OS adapter smoke test for `OsKeyring` and `OsSecretBackend`.
     - Sentinel secret leakage: verified absent in all error variants and debug outputs.
