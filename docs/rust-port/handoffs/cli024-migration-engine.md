`input_directories` and `input_files` store the exact deterministic, synthetic
input tree for each added case. They are not handwritten expected reports.
The generator verifies unchanged source bytes and absent destination/backup
paths for dry-runs. The Rust replay recreates those inputs and compares the
entire case directory manifest before/after, as well as stdout/stderr/exit.
Fixture paths reject absolute paths and parent traversal.

The existing filesystem case `migration` gains an executable Rust consumer:
process exit, normalized stream lengths and SHA-256, full root inventories,
file payload hashes/sizes, and Unix modes for the source, destination, state
and backup marker. The legacy source is independently checked unchanged.
Directory allocation size is deliberately excluded from equality because it
is filesystem-specific; directory names, types and Unix modes stay asserted.
Windows ACL and native platform behavior remain separate proof obligations.
