## Oracle and acceptance

- defaults: `data_dir = "~/.local/share/symeraseme"`, port `8000`, encryption and
  remote access disabled;
- precedence: defaults → global `$XDG_CONFIG_HOME/symeraseme/config.toml` when
  absolute (otherwise `$HOME/.config/symeraseme/config.toml`) → project
  `.symeraseme.toml` in the current directory → non-empty `SYMERASEME_*` env;
- supported env names: `DATA_DIR`, `DB_DIR`, `ENCRYPT_DB`, `PORT`,
  `ALLOW_REMOTE`;
- bool coercion: bool, 0/1 and trimmed case-insensitive true/false, yes/no,
  on/off; integer coercion for TOML/env port;

  values fail with field context;

  the supplied home, NUL/empty paths fail, and port must be `1..65535`;
- storage resolution returns absolute DataDir/DBDir/DBPath and the user-scoped
  encrypted temp directory without shared-temp leakage.
