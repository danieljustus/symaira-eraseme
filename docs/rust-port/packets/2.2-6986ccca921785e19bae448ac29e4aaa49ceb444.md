## Acceptance slice

Port the pure timestamp and confirmation-link behavior against the Go oracle.
Time parsing trims whitespace, accepts the documented ISO/SQLite/RFC layouts,
interprets naive timestamps as UTC, returns UTC values, distinguishes empty
from malformed input, and formats canonical ISO `+00:00` and SQL wall-clock
bytes with seconds precision. Confirmation extraction keeps only HTTPS links
whose host is in the fixed broker allowlist (including the documented `www.`
normalization), removes trailing punctuation, deduplicates and sorts by path
length then URL length. Hostile schemes/hosts/malformed links must be rejected.

Keep browser/click side effects out of this pure slice. Add property coverage
for timestamp round trips and hostile URL inputs; compare expected bytes/results
with the existing Go fixtures and never broaden normalization silently.

## Quality/security recovery

- Reject backslashes anywhere in extracted HTTPS candidates before authority
  parsing; browsers can reinterpret them as URL separators and bypass a naive
  host allowlist.
- Reject URL userinfo before host validation; otherwise an allowlisted suffix
  can hide an attacker-controlled authority prefix.
