# Symaira EraseMe — OpenDesign handoff

## Purpose

This project is the design handoff for **Native macOS + CLI/MCP**. Start here instead of guessing which render, source, or prototype is current.

## Open first

- `asset-board.html` — visual index of UI/UX and public assets.
- `eraseme-companion.html` — interactive UI/UX reference.
- `DESIGN.md` then `tokens.css` — normative local design rules.
- `assets/manifest.json` and `assets/provenance.json` — machine-readable handoff.
- `RELEASE_ASSET_GUIDE.md` — where each export belongs.
- `QA_AND_STATE_LEDGER.md` — verified states, checks, and honest production gates.

## Boundary

The prototype is a visual reference, not proof that the production client implements every state.

## Apple status

Current repository icon sources are mirrored under `assets/brand/`; an OpenDesign copy does not replace the release catalog.

## Vollständiges Repository-Programm

- `symaira-eraseme-complete-program.html` — 7 End-to-end-Programme mit 39 Schritten und 39 Pflichtzuständen.
- `PROGRAM.md` — kompakte Programmliste.
- `program-manifest.json` — maschinenlesbare Abdeckung.
- `QA_PROGRAM.md` — verifizierte Interaktionen und Releasegrenzen.
