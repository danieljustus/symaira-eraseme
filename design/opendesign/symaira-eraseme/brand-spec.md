# Symaira UI Foundation — Brand Spec

## Tokens
- `--bg`: `#0D0C0A`
- `--surface`: `rgba(18, 17, 14, 0.65)`
- `--fg`: `#F5F4F0`
- `--muted`: `#B5AEA5`
- `--border`: `rgba(255, 255, 255, 0.06)`
- `--accent`: `#E5C397`

## Typography
- Display: `-apple-system, BlinkMacSystemFont, "SF Pro Display", sans-serif`
- Body: `-apple-system, BlinkMacSystemFont, "SF Pro Text", sans-serif`
- Mono: `ui-monospace, SFMono-Regular, Menlo, monospace`

## Observed rules
1. Warm-black canvas with Champagne/Sand as sparse brand signal.
2. Technical structure comes from blueprint grid, hairline borders, mono metadata, and lifecycle semantics.
3. Standard opaque surfaces carry data; translucent material is reserved for chrome.
4. Native macOS rhythm: split-view navigation, compact 34px controls, 10/16/20px radius ladder.
5. State is never communicated by color alone; every lifecycle badge includes a readable label.

**Summary:** A local-first macOS operations surface that makes privacy work auditable without pretending to be a cloud dashboard.
